# Research source files

These originals are kept separately from the optimized assets used by the website. The page serves only `index.html` and `static/`; processing scripts live in `scripts/`.

- `presentations/GelSphere.pptx` — the supplied presentation, formerly `presentation (1).pptx`
- `blender/GelSphere-exploded.blend` — original exploded sensor model
- `animations/` — original optical and rolling-mechanism animations
- `figures/` — source figures, cross-sections, and thumbnails
- `figures/feather/` — reference, specular, and matte normal maps plus correspondence evaluation
- `videos/` — original recordings, force experiment, and PowerPoint video export
- `papers/` — supplied research paper
- `archive/gelslam-illustrations/` — superseded website illustrations, preserved for reference

`videos/force-estimation.mp4` was supplied as `temp.mp4`. `videos/single-frame-screen-recording.mov` was the timestamped screen recording. The bronze/gray filenames now use specular/matte. Originals were moved without re-encoding. `videos/gelslam-powerpoint-export.mp4` is a native PowerPoint export of source slides 29–31.

Authoring inputs are ignored by Git and remain local; previously tracked originals retain their history at their new locations. The website deploys the optimized files in `static/`. The PowerPoint deck, Blender model, and new raw recordings are not uploaded with a website deployment.
